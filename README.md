# روضتي برو - Rawdati Pro

نظام متكامل لإدارة الروضات والحضانات الأهلية على حاسبات ويندوز.

الحضور والانصراف مع المخولين بالاستلام، الأقساط والوصولات، الملف الصحي للأطفال، اليوميات للأهل عبر واتساب، الباصات، المخزن، والتقارير المالية.

## التحميل

### [⬇️ تحميل آخر إصدار](https://github.com/tweety24H/rawdati-pro-releases/releases/latest)

من الصفحة اختر الملف `Rawdati-Pro-v1.0-Setup.exe` تحت قسم **Assets**.

## التنصيب

1. شغّل ملف التنصيب ووافق على شروط الاستخدام.
2. إذا ظهرت شاشة زرقاء من ويندوز، اضغط **More info** ثم **Run anyway**. هذا طبيعي مع البرامج الجديدة.
3. عند أول فتح تظهر شاشة التفعيل وفيها **رقم الجهاز**. أرسله لنا على واتساب لتحصل على كود التفعيل.

دليل الاستخدام الكامل يُنصَّب مع البرنامج، ويفتح من: الإعدادات ← حول البرنامج ← دليل الاستخدام.

## المتطلبات

- ويندوز 10 أو 11 (64 بت)
- لا يحتاج إنترنت للعمل اليومي. بيانات الروضة تبقى على حاسبتكم فقط.

## التحديثات

عند صدور إصدار جديد تظهر رسالة للمديرة داخل البرنامج. التحديث يُنصَّب فوق الإصدار الحالي، والبيانات لا تتأثر.
